repository artifacts and the command that should be used to inspect or rebuild
each item. It is a provenance index, not a replacement for the frozen files.

The reviewer-facing text results are stored under
`docs/reproducibility/results_bundle/`. Public reproduction commands install
that bundle into `results/` automatically, without overwriting an existing
conflicting file.

- Coverage-replicate seeds: `101, 202, 303`.
- Quick demo seed: `42`.

The machine-readable seed map is `config/experiment_seeds.json`.

The local W3.8 Additional file 3 adds both A. thaliana replication cohorts.
In the first three-seed cohort, mean delta r was `0.2370` (95% CI `-0.0776`
to `0.5516`; paired t p = `0.0834`), so that test was directionally positive
but non-confirmatory. The second pre-specified six-seed cohort confirmed the
same single-species contrast: mean delta r = `0.3008`, 95% CI `0.1624` to
`0.4391`, paired t p = `0.0025`. The 12-seed pooled analysis is reported as
secondary sensitivity only.

W3.7 reordered the Results section by claim type: model design,
controlled GC ablation, six-species scope/gate, uncertainty, independent
indel ablation, descriptive cross-tool/downstream fidelity, computational
scaling, and claim summary. W3.8 inserts the second replication cohort as
Table 6 and moves the later tables to Tables 7-10.

The phase-2 cohort is a new pre-specified experiment, separate from the
original cross-species gate. Its endpoint-only implementation reproduces the
six first-cohort top-level `pearson_r` values exactly before it is used; the
equivalence check is recorded in the phase-2 result document. The result is
stored under `docs/confirmatory_ath_bin_replication_phase2_result.md`.
