# W3.8 对评估意见的回应

这轮修改没有停在措辞层面。我们重排了 Results 的论证顺序，补充了模型方法、计算性能和仓库说明，并新增了一个在运行前锁定终点与分析规则的拟南芥第二轮独立复现队列。原来的六物种 gate 和第一轮复现结果均未追溯修改。

## 摘要

Background 现在按“错误依赖局部 GC -> 常用模拟器主要暴露全局误差-> 常用指标不一定测量局部 GC 误差”展开。Results 压缩了实验细节，保留受控消融、六物种范围、独立复现和下游一致性。Conclusions 与Background 提出的两个问题逐项对应。

## 背景

补充了 GC 影响长读长错误的机制解释，包括局部碱基组成、孔道信号与动力学、二级结构、重复区域比对歧义。Figure 1 现在有明确的分析目的、指标含义和主要观察。对 context-aware simulation 的比较改为引用真正相关的模拟研究方向，而不是把 CycSim 当作长读长模拟器。

## 结果

Results 已按证据顺序重排：模型与测量问题、受控 1-bin 对 GC-aware消融、第二轮独立复现、六物种范围和预注册 gate、不确定性、独立 indel消融、外部工具与下游一致性、计算性能、结论边界。每一块都说明它能支持什么以及不能支持什么。新增 Table 6 汇总 discovery、第一轮复现、第二轮复现和 12-seed 敏感性分析。

## 方法

补充了 `M/S/I1-I3/I4+/D1-D3/D4+` 状态定义、transition matrix 的含义、训练计数与 hierarchical smoothing、读段生成流程和 worker并行机制。软件版本移到独立的 `Software and versions` 小节，不再插入核心方法叙述中间。

## 代码仓库

README 增加了 reviewer quick start、核心模块关系和计算性能命令。`--workers` 是正式参数，`--threads` 只保留为兼容别名。新增离线小fixture、参数拼接回归测试、资源 benchmark 和第二轮复现统计脚本。`--quick-reproduce` 的数据准备参数已修复，并加了测试，避免再次出现把续行参数当成独立命令执行的运行时错误。

## 新增的独立复现

协议在运行前固定：A. thaliana、10x、profile-matched、1-bin 对 5-bin、新 seeds 77、88、99、111、122、133，主要终点为 seed 内 5-bin 减1-bin 的 GC-curve Pearson r，双侧 paired t-test，alpha = 0.05，一次性分析，不根据结果改 seed、终点或 bin 数。

结果：mean delta r = 0.3008，95% CI 0.1624 到 0.4391，p = 0.0025。第二轮独立队列达到预设终点，支持把拟南芥中的 GC 条件化效应写成单物种确认性结果。

把 discovery 3 个 seed、第一轮 3 个 seed 和第二轮 6 个 seed 合并后，12-seed 敏感性分析为 mean delta r = 0.2549，95% CI 0.1796 到 0.3302，p <0.0001。合并分析只作为敏感性分析，不替代原预注册 gate。

## 没有按原句照改的地方

CycSim 不是长读长 sequencer simulator，当前稿件中的 [14] 也不是CycSim。我们没有为了迎合这条意见加入错误引用，而是补充了真正相关的context-aware simulation 和 simulator benchmark 比较。

线程问题在现有代码中无法复现。当前生成器提供 process-level workers、参数校验、单元测试和 1/2/4-worker 扩展性 benchmark。如果仍有具体报错，需要保留原始命令、操作系统和 release tag，再按那个版本定位。

## 当前边界

六物种预注册 gate 仍未通过，因此全文不写成所有物种普遍优于现有工具。当前支持的表述是：GC 条件化在具有明显局部 GC 结构的基因组中产生可测的方向性效应，受控 1-bin/5-bin 对比和拟南芥独立复现用于支撑机制层面，人类 chr21 30x 的 R3/R5 排名用于支撑真实数据锚定层的一致性。
