# W3.6 response to editor evaluation

## Summary

W3.6 is a local major-revision pass. It does not change the frozen scientific
decision: the six-genome GC effect remains directional, the strict
cross-species gate remains unmet, and the independent A. thaliana cohort
remains directionally positive but non-confirmatory. The revision addresses
the editorial issues in framing, methods exposition, results organisation,
computational reporting and repository usability.

## Abstract

* Rewrote the Background to connect three points in order: long-read error is
  context-dependent; common simulators expose a global process; common metrics
  do not directly measure context-dependent error.
* Shortened the Results and moved detailed numbers out of the Abstract.
* Rewrote the Conclusions so that the model, evaluation instrument, statistical
  scope and computational scaling answer the questions raised in the
  Background.

## Background

* Added a mechanism paragraph explaining how local GC can affect nanopore
  kinetics, signal, secondary structure and alignment ambiguity, and why a
  global error rate can miss local structure.
* Added an explicit interpretation of Fig. 1: what the panels show, what the
  curve shape means, and why the contrast motivates GC-conditioned transitions
  and GC-stratified evaluation.
* Added a direct comparison with context-aware simulation for parameter
  optimisation [9] and a recent simulator benchmark [11].

The editor note attributes CycSim to reference [14]. In the current
manuscript, [14] is SAMtools, and CycSim is a metabolic-model tool, not a
long-read sequencing simulator. W3.6 therefore compares against the relevant
context-aware work already in the citation set instead of adding an
unsupported comparator.
