# Teacher framework alignment

Date: 2026-09-22

## Three innovation points

1. **GC-conditioned error modeling.** The model conditions transition
   probabilities on local GC content, with profile-matched one-bin,
   five-bin, ten-bin, and twenty-bin controls. The primary figure is
   `figure_i1_gc_aware_model`.
2. **Matched-data cross-tool benchmarking.** errHMM-GC (ours), NanoSim,
   PBSim3-sample, and badread are evaluated on the same references,
   depth, training subset size, and sampling protocol. The primary figure
   is `figure_i2_cross_tool_benchmark`.
3. **Task-aware evaluation beyond read distributions.** Simulated reads
   are carried through alignment, variant calling, and assembly, with
   read-level quality and downstream utility compared explicitly. The
   primary figure is `figure_i3_task_aware_evaluation`.

Each primary figure is a multi-panel canvas with the following supporting
panels:

| Figure | Main panel | Supporting panels |
|---|---|---|
| I1 | Profile-matched GC-bin response | k-mer gain, model-implied error, state-space, coverage, provenance |
| I2 | Cross-tool composite | subscore heatmap, rank matrix, k-mer PCA, species profile, measurement coverage |
| I3 | Four-layer evidence matrix | mapping, variant F1, assembly identity, internal-route response, read-to-downstream correlation |

## Evaluation matrix

The implementation uses the following naming to prevent ambiguity:

- `errHMM-GC (ours)`: the submitted GC-aware model.
- `errHMM-1bin (ours)`: the one-bin, non-GC-aware control.
- `Sample-A (ours)`: the empirical sampling baseline.
- `PBSim3-sample (external)`: `pbsim --strategy wgs --method sample`.
- `PBSim3-HMM (external)`: reserved for the native PBSim3 error-HMM mode;
  it is not the submitted errHMM-GC model.
- `NanoSim (external)` and `badread (external)`: the other external tools.

## Layer outputs

| Layer | Internal panel | External panel |
|---|---|---|
| Reads / FASTQ | six species x three routes x two legacy replicates | three species x four tools |
| Alignment / BAM | six species x three routes x two replicates | generated by `titan_framework_external.sh` |
| Variant calling | six species x three routes x two replicates, truth VCF | generated by `titan_framework_external.sh` |
| Assembly | six species x three routes x two replicates | generated by `titan_framework_external.sh` |
| Phasing | not claimed for haploid simulated panels | requires diploid HiFi truth; kept separate |

The figure generator treats every missing cell as `NA`. A missing cell is
never converted to a zero or a performance claim.

## Reproducible algorithm entry point

The core improvement loop is not embedded in the plotting code. It is
implemented in `scripts/reproduce_gc_improvement.py` and exposed through:

```bash
SPECIES=Ecoli COVERAGE=10 SEED=42 THREADS=4 bash reproduce.sh --gc-demo
```

This trains `errHMM-GC` and `errHMM-1bin` from the same real BAM, verifies
that the GC-conditioned transition matrices contain actual between-bin
structure, resimulates both routes with the same reference/coverage/seed,
and evaluates both against the same real reads. The output includes a
machine-readable C-minus-B delta and a pass/fail gate. The gate is not
allowed to alter data.
